# Lance Adrian portfolio

Static site, no build step. Deploy the folder on Vercel (framework preset: Other).

- `index.html`  page structure and static copy (hero, contact)
- `css/styles.css`  all styling; colors and fonts are the variables in `:root`
- `js/data.js`  projects, skills, stats. Edit this to change content
- `js/main.js`  rendering and behavior (card stacks, carousel, marquee, GitHub repos)
- `assets/`  images
